# Awesome DSH

> The community ecosystem and plugin directory for DeepSeek Harness.

**Awesome DSH** is an independent, community-maintained directory for plugins, agents, skills, libraries, tools, integrations, examples, and resources built for or useful with [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness).

## Registry

The second phase of Awesome DSH uses structured metadata instead of maintaining only Markdown links.

```text
registry/
├── schema.json
└── plugins/
    └── example/
        └── plugin.json
```

This registry is intended to power future search, filtering, compatibility checks, project statistics, and a web-based plugin directory.
